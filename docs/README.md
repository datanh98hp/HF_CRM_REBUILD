Mỗi file P0 mô tả mục tiêu, phạm vi, phụ thuộc, tiêu chí hoàn tất và cấu hình còn cần. Trạng thái triển khai chuẩn (đã đối chiếu với mã nguồn ngày 2026-11-20) nằm ở [implementation-status.md](phase-0/implementation-status.md); các file P0 không thay thế báo cáo đó. README và DESCRIPTION trong repo root cũng được đồng bộ theo cùng trạng thái.

Với tính năng có giao diện, triển khai route frontend trong cùng lát cắt sau khi API backend tương ứng sẵn sàng; chỉ tách sang giai đoạn khác khi có yêu cầu hoặc phụ thuộc được ghi nhận trong [hướng dẫn dự án](../AGENT.md#13-frontend-and-sidebar).
